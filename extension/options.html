Behavior

Connection

Where the extension sends captured chats.

Local backend

Run mnueron dashboard on your machine to start it.

Default http://localhost:3122.

Hosted backend

Use the mnueron.com hosted service instead of (or alongside) local.

Default https://mnueron.com. Override only for self-hosted.

Ambient context

Surface related memories from your store while you type.

Scope ambient suggestions to one namespace. Click Test connection (General) if empty.

Backfill

Import past chats and migrate between backends.

Namespace prefix

Captured memories save under <prefix>-<site> (e.g. web-claude).

Re-import backfilled chats

Clears the "already imported" cache so the next Backfill pulls every Claude chat through the latest scraper. The hosted backend dedupes by source_ref, so re-importing updates memories instead of duplicating them.

Migrate local → hosted

Copy every memory from your local mnueron store to the hosted account. Idempotent — existing source_refs are deduped server-side.
