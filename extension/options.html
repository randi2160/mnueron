mnueron settings

Where the extension sends captured chats, and which sites it captures from.

Local backend
Default http://localhost:3122. Run mnueron dashboard in a terminal to start it.
Hosted backend (optional)
Default https://mnueron.com. Override only if you self-host the backend.
Capture behavior
Memories save under <prefix>-<site>, e.g. web-claude.
Migrate local → hosted

Copy every memory in your local mnueron store up to the hosted account configured above. Idempotent — re-running won't duplicate memories (existing source_ref values are deduped server-side).
